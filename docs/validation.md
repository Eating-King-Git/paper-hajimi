## 本地运行逻辑测试

```text
python tools/test_face_game.py
python tools/validate_face_game.py
```

测试脚本支持PATH中的g++/clang++；Windows也可自动寻找已安装的Visual Studio C++工具。测试不连接硬件，不修改厂商SDK。GitHub Actions执行逻辑测试和资源检查，不进行两板烧录。

如果修改了资源，先执行`python tools/create_asr_face_game.py`；如果修改了ESP32生成设置，执行`python tools/create_face_game.py`。重新测试后再编译、烧录。

## 自己的样机验收单

- [ ] ESP32启动版本正确，屏幕正常，ASR握手link=1。
- [ ] 无唤醒时左右靠近分别有反馈，持续遮挡不重复摆头。
- [ ] 唤醒明确指定一边，摸对、移开后自动邀请另一边。
- [ ] 两侧结束邀请夸奖，四种夸奖口令均能进入同一个回应流程。
- [ ] 再来一次为三轮交替；摸错、两侧同时遮挡和超时均能退出/提示。
- [ ] 舵机方向正确、无顶住/持续嗡鸣，动作时两板不重启。
- [ ] x停止自动、a恢复，新事件才重新动作。
