# 硬件、供电和可复用零件

当前引脚以[接线表](wiring.md)为准。本项目没有统一采购套件或承诺成本，优先复用旧小车零件。

| 当前使用 | 规格 / 选择依据 |
|---|---|
| GOOUUU ESP32-S3-CAM V1.5 | 实物与板型资料核对，带摄像头和两个USB-C；当前不启用摄像头/PSRAM |
| SSD1306 OLED | 128×64、I²C四针，程序扫描0x3C/0x3D |
| ASRPRO V2.0 | 板载麦克风、USB串口与功放；两条串口方向使用不同UART引脚，见接线表 |
| 红外避障模块×2 | 低电平触发，当前用3.3V；两侧分别朝外，避免对射或长期被桌面挡住 |
| SG90×1 | 实物标签9g，50Hz PWM，单独5V供电，共地 |
| 喇叭 | 使用与ASR板匹配的现有喇叭，未核实标签，不虚填阻抗与功率 |
| 蓝色多路降压板 | 商家图标MP1584EN，输入6～24V，5V最大3A、3.3V最大1A；不是对持续带载能力的实测 |

多个电源插针共享输出，不是每个插口都有独立3A。蓝板绿色VOUT=VIN不是稳压输出；某批次板上输入丝印与商品参数不同，本项目按保守的6～24V商品范围记录。使用前仍需实测极性、电压和负载压降。

## 有，但当前没启用

- STM32F103C8、TB6612FNG、TT减速电机/车轮、HC05、超声波等旧车零件。
- 板载摄像头。
- 资料中出现的传感器不代表已安装；没有将TTP223计入当前模块。

TT电机商品参数：减速比标称1:48，3V空载90rpm±10%、≤150mA；6V空载200rpm±10%、≤200mA，轮径约65mm。空载电流不能代替启动/堵转电流，未据此承诺身体升降或载重能力，也不要直接给这些电机接9V。

## 复刻与验证边界

作者报告当前样机可用，但没有提供续航、连续运行时长、带载转矩或精确角度的台架测试数据。换电源、换板、装上纸壳头部后应重新确认电压、供电稳定性、转动空间和方向。

原厂PDF、商品截图、安装包及来源不明的第三方代码没有随本仓库再分发。请根据实物板型向对应厂商索取资料，不能拿普通ESP32教程的引脚直接套用。
