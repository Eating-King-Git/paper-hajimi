# 从零做到会互动：项目过程

灵感来自“小纸壳机器人”作品和教程。这个项目从旧小车零件开始，新增了离线语音互动流程，并丰富了OLED表情。作者现已提供纸壳头部样机的照片和演示视频，结构尺寸与打印模板待整理。

| 阶段 | 留下的工程 | 学到了什么 |
|---|---|---|
| 一：点亮眼睛 | `DeskPetScreen` | I²C地址扫描、四线接法、基础眨眼 |
| 二：感应靠近 | `DeskPetInteraction` | 单路红外、表情状态、区分显示正常和感应正常 |
| 三：听见指令 | `DeskPetVoice` | ASR事件串口与表情连接；早期裸字节协议 |
| 四：让表情更明显 | `DeskPetExpressions` | “前进/后退”需要肉眼可区分的反馈 |
| 六：自由感应 | `DeskPetBehavior` | 语音工具暂时不可用时，也能先推进红外互动 |
| 七：先单测舵机 | `DeskPetHeadTest` | 独立5V、共地、保守范围、手动停止 |
| 八：语音表情转头 | `DeskPetHeadMotion` | 把事件、表情与动作联系起来 |
| 九：双脸主动引导 | `DeskPetFaceGame` | 双向串口、播放完成回执、两路红外、连续引导 |

这些阶段入口保留用于学习。旧版注释中的引脚/空置要求只适用于该阶段；**完整复刻从最新DeskPetFaceGame及当前接线表开始**。V5曾用于主动播报探索，其未整理的个人工程未纳入公开版，因此编号不连续。

## 真正遇到的坑

1. **编译通过但串口连不上。** COM号会变化，TTL/OTG接口不同，串口也可能被监视器占用。
2. **语音能回答，屏幕却没有反应。** 逐段查看事件接收和表情更新，而不是只判断“喇叭响了”。
3. **欢迎语正常，但一直link=0。** 实际少接ESP32 G47→ASR PA3；只接PB5→G14只能收到语音事件，无法让ESP请求播放。
4. **天问积木导入后少参数。** 可选asr_vol/baud扩展缺失，生成了空参数函数；改成内置数字积木3和9600。
5. **未唤醒时摸脸没反应。** 原版只接受游戏内输入；V9.2加入独立自由摸脸。
6. **有时识别不到。** 分离两路消抖、缩短整屏刷新阻塞，允许提示期间开始靠近；线材和光学问题仍需要实物排查。
7. **转头不够明显。** V9.3把侧向脉宽偏移从±100扩大到±200μs，保留渐进回中。
