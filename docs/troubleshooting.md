# 调试时先看哪一项

[快速开始](quickstart.md) · [接线表](wiring.md)

| 现象 | 优先检查 |
|---|---|
| `Could not open COM...` | 拔插观察当前端口，重新选择；关闭占用串口的软件/监视器，确认USB是数据线 |
| `No serial data received` | USB接ESP32的TTL；必要时按住BOOT、短按RST、松开RST后松开BOOT，再上传 |
| OLED完全不亮 | 断电检查3V3/GND/SDA41/SCL42，查看I²C扫描；0x3C或0x3D以实际日志为准 |
| 上电能说话但叫它没联动 | 看`ASR EVT,WAKE`和`link`；欢迎语并不证明双向串口通了 |
| 有`EVT,WAKE`但始终`link=0` | 重点查**G47→ASR PA3**；PB5→G14只负责另一个方向。不要接PB6 |
| 新版播放报`ERR,...,ID/RESOURCE` | 重新打开V9.3天问工程生成全部语音资源并下载，不能只更新ESP32 |
| 天问提示缺`asr_vol`/`baud` | 使用本仓库V9.3工程，它用普通数字积木；不要在缺块的旧工作区继续编译 |
| 红外偶尔不识别 | 先看原始`IRraw`是否变化；检查模块朝向、电位器、接触、光照和两模块互扰，软件不能修复接触不良 |
| 表情变了但舵机不动 | 查独立5V供电、共地、G1和`auto=1`；串口小写`a`恢复自动，再移开重新靠近 |
| 转头方向反了 | 核对左右以面对玩具为准；必要时改`HEAD_REVERSED`，不要随意改GPIO |
| 喇叭异响或动作时重启 | 先关闭舵机支路，检查供电稳定、共地和线材；确认蓝板5V没有并入USB 5V |
| 提示摸脸后一直没有下一句 | 先按提示选侧、再移开；持续遮挡不会反复算得分，动作回中后才进入下一轮 |
| 夸它有时不回应 | 等当前播报结束再说已配置口令；本版不保证边说边听，也不识别任意自然语句 |

## 串口日志

ESP32 USB串口：**115200**。两板通信：**9600**，两个数不要混淆。

```text
V9.3 state=... target=LEFT IRraw=0 IR=0 settle=0 face=0 link=1 auto=1
```

- `IRraw`：0无遮挡，1左，2右，3双侧。是程序把低电平转换后的位掩码。
- `IR`：消抖后的掩码；`settle`：还在变化的位。
- `link=1`：已收到READY；不代表所有播放/动作都完成。
- `ASR ACK,n`：请求被接受；`ASR DONE,n`：该次语音播放完成。
- `DISPLAY ACK`：屏幕帧发送完成，不是人眼或摄像头对画面的验证。
- `HEAD PLAN COMPLETE`：程序已发出回中指令，不是舵机位置传感器读数。

## 串口手动检查

| 单个字符 | 操作 |
|---|---|
| `x` | 停用自动转头/游戏并停止PWM；舵机电源仍在 |
| `a` | 恢复自动，等待下一次新事件 |
| `k` | 手动中位，进入手动模式 |
| `j` / `l` | 手动左/右；先发k，结束后发a恢复 |
| `w` / `p` / `g` / `q` | 模拟唤醒/夸奖/游戏/退出；需语音握手成功 |
| `0`～`9` | 测试表情，取消当前游戏 |

模拟事件测试的是控制流程，不代表麦克风识别成功。发Issue时提供板型、版本、连接和相关启动日志即可，不要上传账号密码、令牌或完整电脑目录清单。
