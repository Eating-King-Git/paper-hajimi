# 怎么和纸壳哈基米互动

[首页](../README.md) · [架构与串口协议](architecture.md)

| 你说/做 | 它的反应 |
|---|---|
| 哈吉米（哈基米同音） | 明确邀请摸左脸或右脸，随后引导另一边 |
| 你好可爱 / 你很可爱 / 你真可爱 / 好可爱 | 三种夸奖回应随机，相邻不重复，继续邀请摸脸 |
| 陪我玩 / 我们玩吧 / 摸摸游戏 | 开始三轮左右交替的摸脸游戏 |
| 再来一次 | 开始新的三轮，起始侧随机 |
| 靠近指定红外 | 笑脸、对应侧转头、随机奖励 |
| 摸错侧 | 提醒另一边；先移开再试，第二次错误则结束 |
| 同时挡住两路 | 提醒一次选一边 |
| 一直没操作 | 提示后结束，不无限催促 |
| 不玩了 / 停止游戏 | 结束游戏、停止动作，正在播报时等当前短句结束 |
| 休息吧 | 困倦表情；新的靠近也可以恢复自由互动 |
| 前进 / 后退 | 保留明显表情、语音和转头，不启动电机 |

## 自由摸脸

没有语音唤醒时，左脸靠近会眨眼并向左转，右脸靠近会爱心眼并向右转，双侧稳定靠近时笑脸轻摆。左右按照你面对玩具的视角。

手持续停留时不反复摆头。语音播报或游戏优先，期间按游戏规则处理；自由模式不主动请求语音，不依赖语音握手。休息不是断电。

## 判定与动作

- 双路各自消抖：靠近40ms确认、离开120ms确认；一侧抖动不阻塞另一侧的自由反馈。
- 提示期间若曾确认双侧无遮挡，随后靠近并保持到播报结束，可计入。开局前就一直挡着仍要先拿开。
- 指定侧输入等待12秒；两轮之间等手离开及动作完成，释放后额外稳定80ms；释放超时8秒。
- 自由动作触发至少间隔900ms，最多保留仍在靠近的最新一侧，不积压长动作队列。
- SG90中心1500μs，左右1300/1700μs，轻摆1400/1600μs。控制脉宽不是实测角度，换舵机或装头部后需重新标定。

## 改台词 / 改动作

1. 编辑`tools/create_asr_face_game.py`中的`PHRASES`、`COMMANDS`。同类口令映射到同一事件；当前14条口令、20条播报。
2. 执行`python tools/create_asr_face_game.py`，同步生成`.hd`、C++和JSON资源表。
3. 在天问重新生成识别/音频资源并下载。若增加新事件/新ID，同时修改ESP32控制器及测试，再更新ESP32。
4. 控制流程在`firmware/DeskPetFaceGame/Interaction.h`。舵机生成参数在`tools/create_face_game.py`，运行后更新当前`.ino`；不要修改冻结V8文件来调整当前版。

增大角度前先确认无机械阻挡和供电稳定。不建议直接全角度扫动。方向相反可调整`HEAD_REVERSED`，但不改变红外左右定义；使用生成器时需同步修改生成设置，避免再次生成覆盖手改。

当前没有头顶传感器，不能仅加一句“摸摸我的头”就自动具备摸头反馈。也没有“听不懂任意一句话”的事件：超时提示表示一段时间没有收到有效操作，不是语义判断。
