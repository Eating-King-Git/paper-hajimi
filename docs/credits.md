# 灵感、来源与第三方边界

## 小纸壳机器人的来历

项目起点是作者在短视频平台看到的“小纸壳机器人”系列。保留的参考截图中：

- **@林缘**：纸壳小机器人作品，屏幕眼睛与简单纸板造型带来的生命感。
- **@Made by Z**：名为“小纸壳机器人制作教程系列”的教学内容，截图展示ESP32-C3 SuperMini、OLED、红外、舵机等组成。

本仓库没有核实原视频的稳定链接，也不据此判断谁是整个创意的最早发明者。未复制再分发截图、视频或作者材料包；感谢这些作品带来的灵感。如需补充准确原始链接，欢迎提交Issue。

## 本项目新增的部分

使用现有 **GOOUUU ESP32-S3-CAM**，并加入 **ASRPRO离线语音模块**。实现了同类口令映射、随机回应、主动指定左右脸、奖励后继续引导、超时提示，以及表情/舵机与双红外的状态协调。

本仓库代码是在这个硬件组合下逐步编写、调试并整理的实现，不宣称“小纸壳机器人”概念、硬件模块或原视频外观是本项目首创，也不是原作者的官方配套代码。
